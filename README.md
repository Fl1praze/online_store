# 🛒 Интернет-магазин на FastAPI

Полнофункциональный интернет-магазин с админ-панелью, построенный на FastAPI с использованием PostgreSQL, Redis, Celery и WebSocket.

## ✨ Основные возможности

### Для пользователей
- 🔐 **Аутентификация и авторизация**
  - Регистрация с подтверждением email
  - JWT токены (access + refresh)
  - Восстановление пароля
  - Смена данных профиля

- 🛍️ **Каталог товаров**
  - Просмотр товаров с фильтрацией
  - Поиск по названию
  - Фильтрация по категориям, цене, наличию
  - Пагинация
  - Детальная страница товара

- 🛒 **Корзина и заказы**
  - Добавление товаров в корзину
  - Управление количеством
  - Оформление заказов
  - История заказов
  - Отмена заказов (pending/processing)

- ⭐ **Отзывы и рейтинги**
  - Оставление отзывов на товары
  - Рейтинговая система
  - Просмотр отзывов других пользователей

- 💬 **Онлайн-чат**
  - WebSocket чат в реальном времени
  - Общение с другими пользователями

### Для администраторов
- 📊 **Админ-панель**
  - Управление товарами (создание, редактирование, удаление)
  - Управление категориями
  - Управление заказами
  - Управление пользователями
  - Просмотр и модерация отзывов
  - Статистика и аналитика

### Безопасность
- 🛡️ **Rate Limiting** (защита от атак)
  - Логин: 5 попыток в минуту
  - Регистрация: 3 регистрации в час
  - Создание заказов: 10 заказов в минуту
  - Добавление в корзину: 30 добавлений в минуту
  - Поиск: 60 запросов в минуту

- 🔒 **Безопасность**
  - Хеширование паролей (Argon2)
  - JWT токены с версионированием паролей
  - Email верификация
  - Защита от CSRF

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- PostgreSQL 15+
- Redis 7+
- Docker и Docker Compose (опционально)

### Установка

1. **Клонируйте репозиторий**
```bash
git clone <repository-url>
cd NewFastAPI
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

4. **Настройте переменные окружения**

Создайте файл `.env` в корне проекта:
```env
# База данных
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASS=your_password
DB_NAME=online_store

# JWT
SECRET_KEY=your-secret-key-change-in-production
ALGORITHM=HS256

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0

# Email (для верификации)
EMAIL_SENDER=noreply@example.com
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASSWORD=your_app_password
```

5. **Создайте базу данных**
```bash
createdb online_store
```

6. **Примените миграции**
```bash
alembic upgrade head
```

7. **Запустите Redis** (если не используете Docker)
```bash
redis-server
```

8. **Запустите Celery worker** (в отдельном терминале)
```bash
celery -A app.celery_app worker --loglevel=info
```

9. **Запустите приложение**
```bash
uvicorn main:app --reload
```

Приложение будет доступно по адресу: `http://localhost:8000`

## 🐳 Запуск через Docker

1. **Создайте `.env` файл** (см. выше)

2. **Запустите все сервисы**
```bash
docker-compose up -d --build
```

Сервисы будут доступны:
- Web: `http://localhost:8000`
- PostgreSQL: `localhost:5432`
- Redis: `localhost:6379`

3. **Примените миграции**
```bash
docker-compose exec web alembic upgrade head
```

4. **Остановка**
```bash
docker-compose down
```

## 🔌 API Endpoints

### Аутентификация
- `POST /auth/register` - Регистрация
- `POST /auth/login` - Вход
- `POST /auth/logout` - Выход
- `GET /auth/verify-email` - Подтверждение email
- `POST /auth/refresh` - Обновление токена
- `POST /auth/change-password` - Смена пароля

### Товары (products/routers.py)

Рассмотрим на примере операций «products/routers.py»:

- запрос `GET /products` для таблицы «products» выводит все товары, которые есть в БД (с фильтрацией по категории, цене, наличию, поиску по названию и пагинацией);
- запрос `GET /products/{product_slug}` для таблицы «products» выводит данные товара, у которого значение «product_slug» в таблице «products» соответствует указанному «product_slug»;
- запрос `PUT /products/{product_slug}` для таблицы «products» позволяет изменить информацию о товаре, у которого значение поля «product_slug» в таблице «products» соответствует указанному «product_slug» (только для администраторов);
- запрос `POST /products` для таблицы «products» создает новый товар в таблице «products» (только для администраторов);
- запрос `DELETE /products/{product_slug}` для таблицы «products» позволяет удалить информацию о товаре, у которого значение поля «product_slug» в таблице «products» соответствует указанному «product_slug» (только для администраторов, товар помечается как неактивный);
- запрос `GET /products/category/{category_slug}` для таблицы «categories», берем slug категории, делаем запрос в таблицу «categories» получаем id найденной категории и ищем равный в таблице products «category_id», также включая подкатегории.

### Пользователи (users/routers.py)

Для таблицы «users» реализованы контроллеры с небольшими изменениями:

- запрос `POST /auth/register` для таблицы «users» создает нового пользователя в таблице «users» (регистрация с отправкой email для верификации);
- запрос `GET /auth/verify-email` для таблицы «users» подтверждает email пользователя по токену из письма, устанавливая поле «is_active» в значение true;
- запрос `POST /auth/login` для таблицы «users» выполняет аутентификацию пользователя, проверяя email и пароль, и устанавливает JWT токены в cookies;
- запрос `POST /auth/logout` для таблицы «users» удаляет JWT токены из cookies;
- запрос `GET /auth/me` для таблицы «users» выводит данные текущего аутентифицированного пользователя;
- запрос `PUT /auth/change_pwd` для таблицы «users» позволяет изменить пароль текущего пользователя;
- запрос `PUT /auth/change_data` для таблицы «users» позволяет изменить данные профиля (имя, фамилия, username) текущего пользователя;
- запрос `POST /auth/logout_other_sessions` для таблицы «users» завершает все другие сессии пользователя путем ротации версии пароля;
- запрос `POST /auth/refresh` для таблицы «users» обновляет access токен используя refresh токен из cookies;
- запрос `GET /auth/admin/users` для таблицы «users» выводит всех пользователей в системе (только для администраторов);
- запрос `PUT /auth/admin/users/{user_id}` для таблицы «users» позволяет администратору изменить информацию о пользователе с указанным «user_id».

### Категории (category/routers.py)

Для таблицы «categories» реализованы контроллеры:

- запрос `GET /categories` для таблицы «categories» выводит все категории, которые есть в БД;
- запрос `POST /categories` для таблицы «categories» создает новую категорию в таблице «categories» (только для администраторов, для создания главной категории не отправлять parent_id);
- запрос `PUT /categories/{category_slug}` для таблицы «categories» позволяет изменить информацию о категории, у которой значение поля «category_slug» в таблице «categories» соответствует указанному «category_slug» (только для администраторов);
- запрос `DELETE /categories/{category_slug}` для таблицы «categories» позволяет удалить информацию о категории, у которой значение поля «category_slug» в таблице «categories» соответствует указанному «category_slug» (только для администраторов, категория помечается как неактивная).

### Отзывы (review/routers.py)

Для таблицы «reviews» реализованы контроллеры:

- запрос `POST /reviews` для таблицы «reviews» создает новый отзыв в таблице «reviews» (только для аутентифицированных пользователей, которые заказывали данный товар, также автоматически пересчитывается рейтинг товара);
- запрос `GET /reviews/product/{product_id}` для таблицы «reviews» выводит все отзывы для товара, у которого значение поля «id» в таблице «products» соответствует указанному «product_id»;
- запрос `GET /reviews/search` для таблицы «reviews» позволяет найти отзывы по названию товара (только для администраторов);
- запрос `DELETE /reviews/{review_id}` для таблицы «reviews» позволяет удалить отзыв с указанным «review_id» (только автор отзыва или администратор, также автоматически пересчитывается рейтинг товара).

### Корзина (cart/routers.py)

Для таблицы «cart» реализованы контроллеры:

- запрос `GET /cart` для таблицы «cart» выводит корзину текущего аутентифицированного пользователя (если корзины нет, создается автоматически);
- запрос `POST /cart/add` для таблицы «cart» добавляет товар в корзину текущего пользователя (если товар уже есть в корзине, увеличивается количество);
- запрос `DELETE /cart/remove/{product_id}` для таблицы «cart» удаляет товар с указанным «product_id» из корзины текущего пользователя;
- запрос `DELETE /cart/clear` для таблицы «cart» очищает корзину текущего пользователя (удаляет все товары из корзины);
- запрос `DELETE /cart/delete` для таблицы «cart» полностью удаляет корзину текущего пользователя вместе со всеми товарами.

### Заказы (orders/routers.py)

Для таблицы «orders» реализованы контроллеры:

- запрос `POST /orders` для таблицы «orders» создает новый заказ на основе товаров из корзины текущего пользователя (товары удаляются из корзины, уменьшается количество товаров на складе);
- запрос `GET /orders` для таблицы «orders» выводит все заказы текущего аутентифицированного пользователя;
- запрос `GET /orders/get_all_orders` для таблицы «orders» выводит все заказы всех пользователей (только для администраторов);
- запрос `GET /orders/{order_id}` для таблицы «orders» выводит детальную информацию о заказе с указанным «order_id» (пользователь может видеть только свои заказы, администратор - все);
- запрос `PATCH /orders/{order_id}/cancel` для таблицы «orders» позволяет отменить заказ с указанным «order_id» (только для заказов со статусом pending или processing, товары возвращаются на склад, отзывы по товарам из заказа удаляются).

### Админ-панель
- `GET /admin/` - Дашборд
- `GET /admin/products` - Управление товарами
- `GET /admin/orders` - Управление заказами
- `GET /admin/users` - Управление пользователями
- `GET /admin/reviews` - Управление отзывами

## 🛠️ Технологии

- **Backend**: FastAPI, Python 3.11+
- **База данных**: PostgreSQL 15, SQLAlchemy 2.0
- **Кэширование**: Redis
- **Очереди задач**: Celery
- **Аутентификация**: JWT (python-jose), Argon2
- **Миграции**: Alembic
- **Тестирование**: pytest, pytest-asyncio
- **Защита**: slowapi (rate limiting)
- **WebSocket**: FastAPI WebSocket
- **Шаблоны**: Jinja2
- **Обработка изображений**: Pillow
